Academic Context

This project is being developed as part of WGU's Data Structures and Algorithms II coursework. I am using it to practice custom data structures, routing logic, algorithmic problem solving, and simulation design.

Time Representation

The simulation represents time as "minutes since midnight" to simplify comparisons and time calculations. For example:

- 1:00 AM = 60
- 2:10 AM = 130
- 9:05 AM = 545

A helper function for converting 12-hour time strings into minutes since midnight is implemented in `data_loader.py`.
